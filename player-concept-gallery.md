# Grand Design AI: Player Concept Gallery

Start with a story, not a character-sheet menu. These original examples show how the Grand Design can turn unusual callings into a Pathfinder 2e character without making every concept secretly the same build.

## What stays consistent

- **The feat chain decides the chassis.** A [Sky Courier] becomes a Monk because the character's story needs repeatable unarmored movement and acrobatics, not because the name resembles any particular PF2e class.
- **One character gets one main engine.** A secondary calling earns an Archetype only when it is regularly relevant. Every other calling remains valuable fiction instead of creating a bloated second character sheet.
- **Big fiction gets a matching cost.** A spectacular rescue, planar refuge, or city-saving moment belongs behind the same level, action, and narrative gates as comparable PF2e effects.
- **The player still owns the character.** The conversion proposes a chassis and explains why; it is not a black-box verdict. If the feat chain does not feel right in play, the entry should be corrected and added to the evaluation corpus.

The complete original examples and their explicit guardrails live in `data/class_scenarios.jsonl` and `data/ability_scenarios.jsonl`.
