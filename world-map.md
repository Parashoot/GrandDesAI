# Zoomable Foundry World Map

The included `foundry-module/assets/atlas/grand-design-atlas.svg` is an original vector atlas, so Foundry's normal canvas zoom remains sharp at every scale. It is a campaign scaffold, not a canonical map.

## Create the main scene

1. In a PF2e Foundry world, create a new **Scene** named `Grand Design Atlas`.
2. Set the navigation type to **Explorable** and the grid type to **Gridless**.
3. Set the scene background to `modules/grand-design-ai/assets/atlas/grand-design-atlas.svg`.
4. Use the native canvas controls to zoom and pan. Add Journal Pins for regions, settlements, factions, and adventure hooks.
5. For regional play, create linked child scenes and use Journal Pins or scene links as the travel layer.

## Replacing the map

For an authorized campaign map, upload a PNG, WEBP, or SVG into Foundry's user data and set the **Grand Design Atlas Asset** world setting to its path. Keep the original source file, license, and attribution in your campaign notes.

## Game structure

Use a zoom tier as a preparation tool:

| Zoom tier | Table use | Typical content |
| --- | --- | --- |
| World | Campaign fronts | Nations, long-distance trade, major threats |
| Region | Arc preparation | Settlements, faction clocks, travel routes |
| Local | Session play | Inns, ruins, encounters, player-owned locations |

The map does not decide canon. It gives the GM an editable place to connect original stories, the conversion corpus, and PF2e scenes.
